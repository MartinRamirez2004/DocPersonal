GIT

¿Que es GIT?

Es un sistema de control de versiones distribuidos.

Cada desarrollador puede tener una copia completa de un repositorio en sus equipos. Permitiendo que cada uno tenga acceso a cambios que se hicieron y que puedan trabajar sobre los nuevos cambios o volver a los anteriores en caso de que sea necesario.

Es demasiado seguro y flexible, donde cada desarrollador puede trabajar en su propia rama.

Configuración de GIT

Git Bash: es una aplicacion la cual sirve como interprete de linea de comandos similar al entorno de Linux, donde podemos realizar comandos y configuraciones de GIT

En configuracion manejamos 3 jerarquias, sistema, global y local.

El alcance local es solamente para el repositorio en el cual estamos trabajando

El alcance global aplica para todos los repositorios que tengamos

Y por ultimo sistema sirve para toda la computadora.

En caso de tengamos diferentes nombres en local, global y sistema siempre se le dara mas prioridad al nombre en el area mas chica, en este caso en local

Comandos de configuracion:

Lista configuraciones: "git config --list". Muestra configuraciones por defecto.

Lista configuraciones global: "git config --global --list". Muestra las configuraciones que hicimos en global.

Configuracion global: git config --global. De igual manera podemos hacer: --local y --system

Configurar usuario: git config --global user.name "nuestro_nombre".

Configurar correo: git config --global user.email "nuestro_email".

Configurar VS editor predeterminado: git config --global core.editor "code --wait". "code" es la palabra reservada que hace referencia a Visual Studio Code

Limpiar consola: clear.

Activar colorizado: git config --global color.ui true. Las salidas en pantalla seran mas coloridas.

Configurar \r y \n: git config --global core.autocrlf true(windows) input(Linux, Unix o Mac). Carriage Return "CR o \r" devuelve el cursor al principio de la linea y Line Feed "LF o \n" mueve el cursos hacia abajo de la siguiente linea. Estas configuraciones son aplicables para windows, Linux, Mac y Unix son diferentes.

Primeros pasos

Comandos para moverse entre directorios:

ls: Muestra carpetas. ls -a: Mostrar archivos ocultos.

pwd: Nos indica donde estamos.

cd Carpeta/: Entrar a la carpeta especificada.

cd ..: Devolverse a carpeta anterior.

mkdir Carpeta: Crear carpeta

rmdir Carpeta: Borrar carpeta


git init: Inicializar git

git add nombre_archivo: Sube un archivo a stage.

git rm --cached nombre_archivo: Quita el archivo subido a stage

git status: Nos muestra informacion de nuestro directorio de trabajo y el area de preparacion.

git commit -m "mensaje de cambio": Hacemos un commit en la rama donde nos encontremos.

git commit -a: Hace un commit saltandose los pasos anteriores.
